CoffeeOnTheWay ☕📦
CoffeeOnTheWay — це  бібліотека на мові C++, розроблена як інформаційна система для персоналізованого підбору кавових напоїв. Проєкт реалізований у рамках навчальної практики та демонструє комплексний підхід до розробки прикладного ПЗ.

🎯 Мета проєкту
Закріплення навичок розробки на C++, що включає:

Архітектурне проєктування: побудова структурованої програми та організація взаємодії між модулями.

Робота з даними: вивчення принципів роботи з бінарними файлами для забезпечення персистентності.

Бізнес-логіка: реалізація алгоритмів аналізу вподобань та автоматизація вибору на основі тестування.

🏗 Архітектура сутностей та сховищ
Система побудована на взаємодії ключових сутностей, кожна з яких має відповідний рівень збереження (Storage):

1. Сутності (Entities / Models)
User (Користувач) — зберігає дані облікового запису користувача для доступу до системи.
Coffee (Кава) — описує характеристики напою (назва, міцність, рівень обсмаження, наявність молока/цукру, опис).
CoffeeCategory (Категорія) — групує напої за ознаками (класична, десертна, міцна тощо).
MyTest (Тест) — містить структуру питань та варіантів відповідей для збору вподобань.
ResultTest (Результат) — фіксує проходження тесту, бали та фінальну рекомендацію.

2. Рівень збереження (Storage Layer)
Кожна сутність обслуговується власним класом-сховищем, що виконує роль Data Access Layer:

UserStorage, CoffeeStorage, CategoryStorage, TestStorage, ResultStorage.

Всі дані серіалізуються у бінарні файли (.dat), що дозволяє зберігати стан системи між запусками.

3. Бізнес-логіка (Business Logic)
CoffeeSelector — центральний модуль-аналізатор. Він обробляє дані з MyTest, порівнює їх із характеристиками з CoffeeStorage та формує об'єкт ResultTest із найбільш релевантним видом кави.

📊 Актуальність
В умовах величезного розмаїття кавової культури, вибір напою стає складним процесом. CoffeeEngine автоматизує цей вибір, підвищуючи комфорт користувача через інтелектуальні алгоритми тестування.
